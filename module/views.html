    Представления автор модуля

    Виды представлений, подготовка данных и отправка формы.

    Представление — это экран модуля. У каждого есть вид, заголовок и пара функций — Load и Submit.

    {
	ID:          "add",
	Kind:        contract.Form,
	Title:       "Новая задача",
	TextCapture: contract.CaptureNone,
	Load:        loadAdd,
	Submit:      submitAdd,
	Fields:      []contract.FieldSpec{ /* ... */ },
}

    Виды

    Вид Что это
    contract.Form форма из объявленных полей
    contract.List список со своим шаблоном
    contract.Detail карточка одной вещи
    contract.Thread лента сообщений
    contract.Picker выбор одного из многих
    contract.Custom своя разметка целиком

    Load

    Load готовит данные. Он получает Ctx: база, пользователь, параметры фразы, время, шина событий.

    func loadAdd(ctx contract.Ctx) (contract.ViewData, error) {
	return contract.ViewData{
		Title: "Новая задача",
		Values: map[string]string{
			"text": strings.TrimSpace(ctx.Param("text")),
			"due":  ctx.Now.Format("02.01.2006"),
			"who":  ctx.User.DisplayName,
		},
	}, nil
}

    Values — предзаполнение формы, Items — данные для списка, Extra — всё остальное, что нужно вашему шаблону.

    Submit

    Submit выполняет действие и говорит, что дальше.

    func submitAdd(ctx contract.Ctx, values map[string]string) (contract.SubmitResult, error) {
	text := strings.TrimSpace(values["text"])
	if text == "" {
		return contract.SubmitResult{
			Errors: map[string]string{"text": "Напишите, что нужно сделать."},
		}, nil
	}
	if _, err := add(ctx, Task{Text: text}); err != nil {
		return contract.SubmitResult{}, err
	}
	return contract.SubmitResult{Message: "Задача заведена.", Pop: true}, nil
}

    Errors перерисовывает форму с ошибками у полей. Pop сворачивает кадр после успеха — это и есть исчезновение после действия. Next отправляет человека в другое представление, если сворачивать рано.

    Чей текст в строке ввода

    TextCapture отвечает на вопрос, что происходит, когда человек пишет в строку, пока открыто ваше представление:

    Значение Что происходит
    CaptureNone весь текст идёт в разбор фраз: человек уходит в другой модуль
    CaptureFull весь текст принадлежит модулю, команды идут со слэша
    CaptureHybrid сначала разбор; если он не уверен — текст ваш

    CaptureFull нужен переписке: сообщение не должно улетать в маршрутизатор. Для большинства модулей верно CaptureNone.

    Выход

    Модулю не нужно думать про /выход: кадр снимает оболочка, и никакого состояния «текущий экран» у модуля нет.
