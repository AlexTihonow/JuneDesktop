    Джун / Свой модуль / Поля и права

    Поля и права автор модуля

    Модуль объявляет поля, а не рисует форму; права живут на уровне поля.

    Поле — это contract.FieldSpec. Из него собираются и разметка, и проверка, и проекция.

    {
	ID:       "text",
	Label:    "Что сделать",
	Type:     contract.Text,
	Aliases:  []string{"задача", "текст", "что сделать"},
	Required: true,
	Order:    1,
}

    Перечень типов — в справочнике: Типы полей.

    Алиасы поля и проекция

    Aliases — это то, как человек называет поле. Из них строится словарь «слово → поле», и фраза, которая называет поле, открывает форму из одного поля:

    смени имя → откроется профиль с одним полем — именем

    Ни строчки разбора текста для этого в модуле нет.

    Предзаполнение

    Default умеет три особых значения: contract.DefaultToday — сегодняшняя дата, contract.DefaultCurrentUser — текущий человек, contract.DefaultAutoInc — следующий номер. Любая другая строка подставляется как есть.

    Права на уровне поля

    {
	ID:           "who",
	Label:        "Исполнитель",
	Type:         contract.Text,
	EditableBy:   []contract.Role{contract.Admin},
	LockedReason: "Поручать задачи другим может администратор.",
}

    VisibleBy решает, видно ли поле вообще. EditableBy решает, можно ли его менять: поле вне прав показывается заблокированным, а под ним — LockedReason. Система объясняет, а не отказывает молча.

    Проверка значений

    Только в Submit, на сервере. Второй реализации проверки в браузере в Джуне нет: две реализации расходятся, и расходятся молча. Required проверяет ядро; всё остальное — ваш код в Submit.
