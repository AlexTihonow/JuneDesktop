    Создать автор модуля

    Одна команда заводит папку модуля; ни один чужой файл не правится руками.

    go run ./tools/newmodule tasks Задачи

    Первое слово — имя модуля латиницей, второе — название для человека.

    Что появилось

    internal/modules/tasks/module.go
internal/modules/tasks/service.go
internal/modules/tasks/module_test.go
internal/modules/tasks/templates/list.gohtml
internal/modules/tasks/migrations/001_init.sql
internal/modules/tasks/styles.css
tests/router/tasks.golden.jsonl

    Заготовка уже работает: фраза «задачи» открывает пустой список.

    Подключение

    go generate ./...

    Генератор пересобирает internal/modules/all.go — единственный чужой файл, который меняется, и меняется он механически. Руками его не правят: при расхождении его перегенерируют.

    Проверка

    go run . --dev

    Наберите в строке ввода «задачи» — откроется список вашего модуля.

    Что дальше

    module.go — это манифест: имя модуля, слова, которыми его зовут, и перечень представлений. service.go — функции Load и Submit из страницы Представления. Поля формы объявляются в манифесте: страница Поля и права.

    Как назвать модуль

    Имя латиницей — это адрес модуля, имя файла с фразами и приставка его таблиц. Менять его потом дороже, чем выбрать сразу: поменяется и имя папки, и имя файла эталонных фраз.

    Слово для человека — то, что увидит пользователь в заголовке кадра и в справке. Оно может состоять из нескольких слов: «Заявки на закупку».

    Если имя занято

    Узел не запустится и скажет, какое слово с каким модулем столкнулось. Посмотреть занятые слова можно в справочнике: Все команды.
