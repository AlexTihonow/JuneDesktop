    Джун / Свой модуль / Манифест

    Манифест автор модуля

    Из манифеста растут интерфейс, разбор фраз, справка и права.

    Манифест — это contract.Module, который возвращает Def(). Всё остальное производно от него.

    func Def() *contract.Module {
	return &contract.Module{
		ID:    "tasks",
		Title: "Задачи",
		Description: "Задачи с текстом, сроком и исполнителем: завести задачу, " +
			"посмотреть свои, отметить сделанной.",
		Aliases: []string{"задачи", "задача", "дела", "поручения"},
		Intents: []string{
			"задачи",
			"добавь задачу позвонить Саше",
			"мои задачи",
		},
		Permissions: contract.AllRoles(),
		Files:       files,
		Home:        "list",
		Views:       []contract.View{ /* ... */ },
	}
}

    Поля манифеста

    Поле Что это На что влияет
    ID имя латиницей адреса, имя таблиц, имя файла с фразами
    Title название для человека заголовок кадра, справка, сайт
    Description одна-две фразы для модели разбор фраз, когда модель подключена
    Aliases слова, которыми модуль зовут разбор фраз без модели
    Intents примеры фраз справка /помощь, подсказки, промпт модели
    Patterns шаблоны фраз с параметрами разбор фраз с хвостом
    Permissions кому доступен модуль видимость и прямой адрес
    Home представление по умолчанию что открыть, когда названо имя модуля
    Files папка модуля через embed шаблоны, миграции, стили

    Description читает модель, а не человек: пишите по делу, без рекламных слов. От того, насколько точно он описывает модуль, зависит, попадёт ли к вам фраза, которой нет в ваших словах.

    Шаблоны фраз

    Шаблон ловит фразу с хвостом и кладёт хвост в параметр:

    Patterns: []contract.Pattern{
	{Re: `^добавь задачу (.+)$`, View: "add", Capture: []string{"text"}, Confidence: 0.9},
}

    Имя параметра из Capture совпадает с именем поля формы — и поле окажется заполненным.

    Частые ошибки

    • Слово из Aliases занято другим модулем. Проверка манифеста при старте скажет об этом прямо, и узел не запустится.
    • Home указывает на представление, которого нет.
    • Description написан для человека: «здесь заводят задачи, очень удобно». Модели это не говорит ничего о том, какие фразы сюда вести.
