    Раздать коллегам администратор

    Чтобы коллеги открыли Джуна, включите раздачу, назовите им адрес и выдайте код подключения.

    По умолчанию Джун слушает только ту машину, на которой запущен. Раздача открывает его всей локальной сети.

    1. Включите раздачу

    Администратор делает это фразой:

    открой джуна коллегам → включит раздачу и попросит перезапустить узел

    То же самое до первого запуска задаётся в файле june.conf рядом с программой: снимите знак # со строки net.lan и поставьте значение true. Раздача начинает действовать после перезапуска — узел слушает сеть с момента старта, и поменять это на ходу нельзя.

    2. Назовите коллегам адрес

    Адрес узла Джун показывает сам:

    сервер → откроется состояние узла с адресом для коллег

    Адрес выглядит как http://192.168.1.10:7777. Вдобавок узел объявляет себя в сети по имени june.local — это удобнее диктовать, но имя появляется не в каждой сети: мультикаст бывает закрыт, а имя — занято другой службой. Экран «Сервер» говорит, объявилось имя или нет; адрес цифрами работает в любом случае.

    3. Разрешите подключения в брандмауэре

    Брандмауэр спрашивает разрешение при первом запуске с раздачей. Что именно ответить на каждой системе, написано на страницах установки: macOS, Windows, Linux.

    4. Выдайте коллеге код подключения

    Коллега открывает адрес и видит поле для кода. Код выдаёт администратор:

    выдай код подключения → откроется список устройств с новым кодом

    Код одноразовый и живёт пять минут: его диктуют голосом через комнату, а не хранят. Десять неверных попыток гасят все выданные коды — это защита от перебора, а не наказание: выдайте код заново.

    После ввода кода устройство появляется в списке и ждёт подтверждения администратора. Подтверждённое устройство узнаёт коллегу само, и пароль ему больше не нужен.

    Если у коллеги не открывается

    Проверьте по порядку: раздача включена и узел перезапущен, адрес назван цифрами, брандмауэр разрешил подключения, обе машины в одной сети. Гостевая сеть Wi-Fi разделяет устройства между собой — в ней коллега не увидит узел даже при верном адресе. Подробный разбор — на странице Решение проблем.
