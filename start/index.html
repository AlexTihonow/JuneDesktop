    Джун / Начало

    Начало

    Поставить Джуна, запустить и открыть коллегам.

    • Что такое Джун Одна строка ввода вместо меню, вкладок и разделов настроек.
    • Установка: macOS Распакуйте архив, дважды нажмите на файл june — Джун откроется в браузере. Ни Go, ни терминал для этого не нужны.
    • Установка: Windows Распакуйте архив, дважды нажмите на файл june.exe — Джун откроется в браузере. Ни Go, ни командная строка для этого не нужны.
    • Установка: Linux Распакуйте архив и запустите файл june из папки пакета — Джун откроется в браузере.
    • Первый запуск Кто становится администратором и какие пять фраз стоит попробовать первыми.
    • Раздать коллегам Чтобы коллеги открыли Джуна, включите раздачу, назовите им адрес и выдайте код подключения.

    Четыре шага от скачанного архива до работающего узла, которым пользуется отдел. Установка занимает несколько минут и не требует ни прав администратора машины, ни интернета после скачивания.

    Джун — локальный мультитул офисных сервисов. Документация описывает то, как он работает сейчас.
