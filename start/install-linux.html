    Установка: Linux

    Распакуйте архив и запустите файл june из папки пакета — Джун откроется в браузере.

    1. Распакуйте архив

    Положите папку туда, где она останется: во временных папках её удалит система вместе с данными.

    unzip june-linux-amd64.zip

    2. Разрешите запуск, если он запрещён

    Большинство распаковщиков сохраняют признак исполняемого файла. Если файл не запускается, поставьте признак сами, находясь в папке пакета:

    chmod +x june june-center

    3. Запустите Джуна из папки пакета

    В браузере откроется вкладка с Джуном по адресу localhost:7777. На машине без графики адрес печатается в консоль: откройте его с другой машины или пробросьте порт по SSH.

    ./june

    4. Назовите себя

    Первый, кто открыл Джуна, становится администратором под именем пользователя системы. Чтобы поменять имя, напишите в строке ввода «смени имя».

    5. Откройте Джуна коллегам, если нужно

    По умолчанию Джун слушает только эту машину. Чтобы коллеги открывали его по сети, снимите знак # со строки net.lan в файле june.conf, поставьте значение true и перезапустите Джуна.

    Порт нужно открыть в брандмауэре. Команду выполняет администратор машины; для firewalld она другая — firewall-cmd --add-port=7777/tcp.

    Адрес для коллег и одноразовый код Джун показывает на экране «Сервер»: напишите в строке ввода «устройства».

    sudo ufw allow 7777/tcp

    Как остановить

    Нажмите Ctrl+C в терминале, где запущен Джун.

    Имя узла в сети

    Джун объявляет себя в сети по имени june.local. Имя не появится, если в сети закрыт мультикаст или занят другой службой объявления имён. Адрес цифрами работает в любом случае, и экран «Сервер» показывает именно его.

    Где лежат данные

    База, файлы и шаблоны лежат в папке data рядом с программой. Резервная копия — это копия папки data целиком; наименьшее, что стоит сохранить, — файл data/june.db.

    Перед копированием остановите Джуна: база пишется в момент копирования, и копия работающей базы может оказаться неполной.

    Настройки запуска

    Рядом с программой лежит файл june.conf. В нём все строки закомментированы знаком # — это значит, что действуют значения по умолчанию. Снимите знак # со строки, чтобы поменять значение.

    Порт, раздача коллегам и папка данных нужны Джуну до того, как он открыл базу, поэтому они живут в файле. Остальное меняется в самом Джуне: скажите строке ввода «настройки узла».

    После правки файла перезапустите Джуна.

    Если порт занят

    Джун не запустится, если порт 7777 занят другой программой или вторым экземпляром Джуна. Снимите знак # со строки net.port в june.conf и укажите другой порт, например 7778.

    Обновление

    Новая версия — новый архив. Распакуйте его поверх старой папки: программа заменится, а папка data останется на месте, потому что её в архиве нет.

    Файл june.conf в архиве есть. Если вы его правили, откажитесь от замены, когда распаковщик спросит, или сохраните копию файла заранее.

    Изменения в базе Джун применяет сам при запуске.

    Запуск при входе в систему

    Узел, который раздаёт Джуна коллегам, должен подниматься сам после перезагрузки машины. Администратор говорит строке ввода «запускай при входе» и подтверждает; отменить — «не запускай при входе».

    Автозапуск ставится для текущего пользователя, прав администратора машины не требует и запускает тот файл june, который лежит в этой папке. Переложили папку — скажите фразу ещё раз.

    Помощник центра вычислений

    Рядом с june лежит june-center. Он нужен только тем, кто отдаёт тяжёлую работу — распознавание сканов, разбор больших файлов — на другую машину. Скопируйте этот файл на ту машину и запустите с кодом, который Джун выдаёт на экране «Центры».

    Для обычной работы Джуна этот файл запускать не нужно.

    Распознавание сканов

    Текст DOCX, PDF, RTF и ODT Джун читает сам. Чтобы искать по отсканированным документам, на машину узла нужно поставить программу tesseract с русским языком и перезапустить Джуна:

    sudo apt install tesseract-ocr tesseract-ocr-rus
