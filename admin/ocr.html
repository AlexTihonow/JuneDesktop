    Распознавание сканов администратор

    Скан становится искомым, если на машине узла установлена программа tesseract.

    Обычный документ Джун читает сам: DOCX, PDF с текстовым слоем, RTF, ODT. Для этого не нужно ничего, кроме самого Джуна.

    Скан — это картинка, а не текст. Чтобы найти слово в отсканированном документе, картинку нужно распознать. Распознаванием занимается отдельная программа — tesseract, — которую узел вызывает, когда она установлена.

    Что работает всегда

    Что Нужно ли что-то ставить
    Текст DOCX, PDF, RTF, ODT нет
    Начальные формы слов для поиска нет
    Подстановка имён в падежах в документы нет
    Распознавание сканов нужен tesseract

    Как проверить

    сервер → покажет, что умеет узел прямо сейчас

    Строка о распознавании говорит, найден ли tesseract и какой он версии. Не найден — сканы принимаются и хранятся, но по содержанию не ищутся; всё остальное работает.

    Как поставить

    tesseract ставится на ту машину, где запущен Джун; вместе с ним нужен русский языковой пакет. Те же команды Джун показывает на экране приёма, когда скан пришёл, а распознавать нечем.

    Система Команда
    macOS brew install tesseract tesseract-lang
    Windows winget install UB-Mannheim.TesseractOCR
    Linux sudo apt install tesseract-ocr tesseract-ocr-rus

    На других системах — по документации самой программы: https://tesseract-ocr.github.io/tessdoc/Installation.html.

    Если русского языка нет, распознавание идёт на установленных языках, и узел об этом говорит.

    После установки перезапустите Джуна и разберите скан заново:

    разбери заново → перечитает файл

    Тяжёлые сканы

    Пачка сканов — это надолго. Разбор идёт в фоне, очередью, и вкладку можно закрыть. Если машина узла слабая, разбор можно отдать другой машине: страница Центры вычислений.

    Если не вышло

    • Скан принят, но не ищется — tesseract не установлен или установлен без русского языка.
    • Распознавание остановилось на большом файле — предел числа страниц задаётся в настройках распознавания: настройки распознавания.
