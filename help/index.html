    Джун / Решение проблем

    Решение проблем

    По симптомам, как их формулирует человек, а не по устройству модулей.

    У коллеги не открывается Джун

    Проверьте по порядку:

    1. Раздача включена и узел перезапущен: страница Раздать коллегам.
    2. Коллеге назван адрес цифрами, а не june.local.
    3. Брандмауэр разрешил подключения: страницы установки macOS, Windows, Linux.
    4. Обе машины в одной сети. Гостевая сеть Wi-Fi разделяет устройства между собой — в ней коллега узел не увидит.

    Не работает адрес june.local

    Имя объявляется по сети мультикастом, а он закрыт не в каждой сети. Кроме того, имя может быть занято другой службой объявления имён. Адрес цифрами работает всегда, и экран «Сервер» показывает именно его: сервер.

    macOS пишет, что файл повреждён

    Файл не подписан сертификатом Apple. Нажмите на него правой кнопкой, выберите «Открыть», затем «Открыть» ещё раз. Подробнее — на странице Установка: macOS.

    Windows не даёт запустить программу

    Нажмите «Подробнее», затем «Выполнить в любом случае». Причина та же: нет подписи. Страница Установка: Windows.

    Порт занят

    Джун не запустится, если порт занят другой программой или вторым экземпляром Джуна. Смените порт в june.conf рядом с программой или остановите то, что занимает порт.

    После обновления пропали данные

    Скорее всего, программа запущена из другой папки: данные лежат рядом с ней. Найдите файл june.db и перенесите папку data к программе. Страница Обновление.

    Документ собрался, а таблица пустая

    Проверьте заголовок шаблона: поля формы объявляет он. Страница Документы.

    Скан не находится поиском

    На машине узла нет программы распознавания либо она без русского языка. Страница Распознавание сканов. После установки разберите файл заново: разбери заново.

    Джун не понимает фразу

    Он показывает кандидатов чипами — выберите нужного, и в следующий раз он поймёт. Посмотрите, какими словами модуль зовут на самом деле: Все команды. Подключённая модель разбирает сложные фразы точнее.

    Код подключения не принимается

    Код живёт пять минут. Десять неверных попыток гасят все выданные коды. Выдайте новый: выдай код подключения.

    Модель подключена, а написано «простой режим»

    Ключ не задан, Ollama не отвечает или значение задано переменной окружения, которая сильнее админки. Страница Модель: Claude и Ollama.
