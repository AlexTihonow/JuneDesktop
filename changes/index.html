    Джун / Изменения

    Изменения

    Что появилось и поменялось для человека, который Джуном пользуется.

    Здесь записано то, что заметно человеку и администратору. Порядок работы над самим Джуном сюда не идёт.

    Текущий выпуск

    Узел работает без отдельных программ. Разбор DOCX, PDF, RTF и ODT, начальные формы слов и подстановка имён в падежах делает сам Джун. Отдельную программу-помощника ставить не нужно. Для распознавания сканов нужен только tesseract: страница Распознавание сканов.

    Настройки узла меняются фразой. Порт, раздача коллегам, модель, автозапуск — всё через строку ввода, без страницы настроек. Страница Настройки узла.

    Пакеты под шесть систем. macOS, Linux и Windows на обычных процессорах и на ARM. В пакете четыре файла, запускается двойным нажатием: страницы установки для macOS, Windows, Linux.

    Настройки запуска в файле june.conf. Порт, раздача и папка данных задаются рядом с программой и переживают обновление. Справочник: Файл june.conf.

    Этот сайт. Руководства для человека и администратора, раздел для автора модуля и справочник, который собирается из кода.

    Что сделать при обновлении

    Ничего сверх обычного порядка: Обновление. Узлам, где стоял отдельный помощник для документов, он больше не нужен — папку с ним можно удалить.
