    Джун / Работа / Файлы

    Файлы

    Перетащите файл в окно — Джун прочитает его, назовёт и положит к себе.

    Файл попадает в Джун перетаскиванием в окно или кнопкой. Дальше узел сам читает текст, определяет, что это за документ, и подписывает карточку. После этого файл находится поиском по содержанию, а не только по имени.

    Самые частые фразы

    файлы → откроется список принятых файлов

    загрузи файл → откроется приём файла

    что я загружал вчера → покажет принятое за вчера

    разбери заново → перечитает файл ещё раз

    Кому виден файл

    Файл принадлежит той переписке, в которую его бросили: кто видит разговор, тот видит вложенное. Отдельных прав у файла нет. Файл, брошенный не в разговор, попадает в личную нить «Мои файлы» и виден только вам.

    Разбор большого файла

    Разбор идёт в фоне, и закрытая вкладка ему не мешает: состояние файла хранится рядом с ним, а не в потоке событий. Пачка сканов принимается целиком — Джун показывает, сколько разобрано.

    Если не вышло

    • Файл принят, но текст не нашёлся — это скан: страница Распознавание сканов.
    • Файл не перетаскивается — проверьте, что вы бросаете его в окно Джуна, а не на значок браузера.
    • Разбор остановился — откройте карточку файла: причина написана на ней.
