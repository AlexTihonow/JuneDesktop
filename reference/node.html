    Параметры узла администратор

    Всё, что администратор меняет фразой «настройки узла».

    Страница собрана из кода. Не правьте её руками: правка пропадёт при следующей сборке. Меняется она там, откуда собрана, — в манифесте модуля, в реестре параметров или в объявлении флага.

    Параметры узла меняет администратор фразой «настройки узла». Часть из них нужна Джуну до того, как он открыл базу, — они живут в файле june.conf рядом с программой.

    Сильнее всего флаг запуска, потом переменная окружения, потом june.conf, потом значение, заданное администратором, и в самом конце — значение по умолчанию.

    Параметр Ключ По умолчанию Где ещё задаётся После перезапуска
    Папка данных data.dir data --data, june.conf да
    Показывать документ на экране до, МБ docs.max_inline 2 нет

    Папка данных · data.dir

    Где лежат база, файлы и шаблоны. Относительный путь считается от папки june.conf, а без файла — от папки программы.

    Показывать документ на экране до, МБ · docs.max_inline

    Готовый документ больше этого не показывается на экране, а скачивается.

    Возможные значения: 1 · 2 · 5 · 10.

    Потолок текста из файла, МБ · files.max_text

    Сколько текста извлекать из одного файла для поиска. Действует для новых файлов.

    Возможные значения: 1 · 2 · 4 · 8 · 16.

    Потолок страниц скана · intake.ocr_pages

    Сколько страниц одного скана распознавать. Число от 1 до 2000; остальные страницы файла ищутся по имени.

    Заданий одновременно · intake.workers

    Сколько файлов узел разбирает сразу. Больше — быстрее пачка сканов и медленнее всё остальное на этой машине.

    Возможные значения: 1 · 2 · 3 · 4 · 5 · 6 · 7 · 8.

    Сколько фраз помнить · llm.cache_size

    Сколько разобранных моделью фраз держать в памяти.

    Возможные значения: 100 · 1000 · 5000.

    Сколько помнить разобранную фразу · llm.cache_ttl

    Повтор фразы в этот срок не идёт к модели второй раз.

    Возможные значения: 10m · 1h · 6h · 24h.

    Глубина рассуждений · llm.effort

    Только для Claude. Для разбора фраз хватает низкой.

    Возможные значения: low · medium · high.

    Модель векторов · llm.embed_model

    Для поиска по смыслу, только у Ollama. Пусто — nomic-embed-text. После смены скажите «переиндексируй».

    Ключ Claude · llm.key

    Хранится в базе узла открытым текстом: резервная копия базы содержит ключ. На экран, в выгрузку и в журнал не попадает.

    Значение секретное: оно не показывается на экране, не попадает в выгрузку настроек и в журнал.

    Имя модели · llm.model

    Пусто — модель провайдера по умолчанию: у Claude claude-opus-5, у Ollama qwen2.5:7b-instruct.

    Разбор непонятых фраз · llm.provider

    Чем разбирать фразу, которую не узнал словарь. Выключено — Джун понимает только знакомые фразы и работает без сети.

    Возможные значения: off · ollama · claude.

    Ожидание ответа модели · llm.timeout

    Дольше модель не ждём: фраза остаётся непонятой, а строка ввода не замирает.

    Возможные значения: `` · 5s · 8s · 15s · 30s · 60s.

    Адрес модели · llm.url

    Пусто — Ollama на этой машине (http://127.0.0.1:11434) или API Anthropic для Claude.

    Открыть коллегам · net.lan

    Слушать всю локальную сеть, а не только эту машину. Коллеги подключаются по одноразовому коду.

    Имя в сети · net.mdns

    Объявлять узел в сети по имени, чтобы коллеги находили его без адреса цифрами. Действует только вместе с раздачей коллегам.

    Порт · net.port

    Порт, на котором Джун открывается в браузере: адрес вида localhost:7777.

    Запускать при входе · node.autostart

    Открывать Джуна, когда вы входите в систему на этой машине. Без прав администратора машины: launchd на macOS, systemd --user на Linux, ярлык в «Автозагрузке» на Windows.
