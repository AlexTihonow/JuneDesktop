    Файл june.conf администратор

    Настройки, которые нужны Джуну до открытия базы.

    Страница собрана из кода. Не правьте её руками: правка пропадёт при следующей сборке. Меняется она там, откуда собрана, — в манифесте модуля, в реестре параметров или в объявлении флага.

    Файл june.conf лежит рядом с программой и читается при запуске. В нём живут только те параметры, которые нужны Джуну до того, как он открыл базу: где база лежит, какой порт слушать, раздавать ли узел коллегам. Всё остальное хранится в базе и меняется в самом Джуне.

    Строка — ключ = значение, знак # начинает комментарий. Относительный путь в data.dir считается от папки самого файла, а не от того каталога, из которого Джуна запустили.

    В пакете лежит файл, где все строки закомментированы: он показывает значения по умолчанию и ничего не меняет. Снимите знак # со строки, чтобы задать своё значение, и перезапустите Джуна.

    Ключ Флаг По умолчанию Что задаёт
    data.dir --data data Папка данных
    net.lan --lan false Открыть коллегам
    net.mdns --mdns true Имя в сети
    net.port --port 7777 Порт

    Полный файл из пакета:

    # Джун — настройки запуска. Остальное меняется в самом Джуне:
# скажите строке ввода «настройки узла».

# Папка данных
# data.dir = data

# Открыть коллегам
# net.lan = false

# Имя в сети
# net.mdns = true

# Порт
# net.port = 7777

    Джун — локальный мультитул офисных сервисов. Документация описывает то, как он работает сейчас.
