    Джун / Справочник

    Справочник

    Полные перечни: команды, клавиши, флаги, параметры узла, типы полей и коды ошибок.

    • Все команды Каждый модуль, его слова, представления и поля.
    • Горячие клавиши Клавиатурная карта строки ввода.
    • Флаги запуска Чем отличается запуск из командной строки.
    • Переменные окружения Что узел читает из окружения при запуске.
    • Параметры узла Всё, что администратор меняет фразой «настройки узла».
    • Файл june.conf Настройки, которые нужны Джуну до открытия базы.
    • Типы полей Чем объявляется поле формы.
    • Коды ошибок Что возвращает модуль, когда действие не выполнено.

    Страница собрана из кода. Не правьте её руками: правка пропадёт при следующей сборке. Меняется она там, откуда собрана, — в манифесте модуля, в реестре параметров или в объявлении флага.

    Справочник отвечает на вопрос «как это называется и что бывает», а руководство — на вопрос «как это сделать». Руководство ссылается сюда и не повторяет перечни.

    • Все команды — каждый модуль: чем открывается, какие представления и поля у него есть.
    • Горячие клавиши — клавиатурная карта строки ввода.
    • Флаги запуска — чем отличается запуск из командной строки.
    • Переменные окружения — что читается из окружения узла.
    • Параметры узла — всё, что меняется фразой «настройки узла».
    • Файл june.conf — настройки, которые нужны до запуска.
    • Типы полей — для автора модуля.
    • Коды ошибок — для автора модуля.

    Джун — локальный мультитул офисных сервисов. Документация описывает то, как он работает сейчас.
